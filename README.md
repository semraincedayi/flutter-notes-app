# 📝 Notes App (Flutter) – Notlar Uygulaması 🗒️

This project is an attempt to develop a notes app using Flutter. ✨ My goal is to create a simple application where users can quickly and easily take notes, edit them, and delete them. 🖊️🗑️
The backend is currently implemented and supports basic operations such as adding, listing, and updating notes. ✅ The frontend is not yet developed and will be added in future stages. 🔜


Bu proje, Flutter kullanarak bir notlar uygulaması geliştirme girişimidir. ✨ Amacım, kullanıcıların hızlı ve kolay bir şekilde not alabileceği, düzenleyebileceği ve silebileceği basit bir uygulama oluşturmak. 🖊️🗑️
Backend şu anda tamamlanmış olup, not ekleme, listeleme ve güncelleme gibi temel işlevleri desteklemektedir. ✅ Frontend henüz geliştirilmemiştir ve ilerleyen aşamalarda eklenecektir. 🔜

## 🔧 Development Status / Geliştirme Durumu

* ✅ Backend: implemented / tamamlandı (add, list, update notes / not ekleme, listeleme, güncelleme)
* 🔜 Frontend: planned for future implementation / planlanan geliştirme
* 💾 Data storage: handled via local database in backend / backend tarafından yerel veritabanı ile yönetilmektedir

The project is still in the development phase and will be expanded with a user interface in later stages. 🚀

Proje hâlen geliştirme aşamasındadır ve ilerleyen süreçte kullanıcı arayüzü ile tamamlanacaktır. 🎨

## 🛠️ How to Use / Kullanım

1. Clone or download the repository / Depoyu bilgisayarınıza klonlayın veya indirin:
   `https://github.com/semraincedayi/flutter-notes-app`
2. Install dependencies / Bağımlılıkları yükleyin:

```bash
flutter pub get
```

3. Run the backend in a Flutter-compatible environment / Backend’i Flutter uyumlu ortamda çalıştırın 💻
4. Once the frontend is implemented, it will integrate with the backend for full app functionality / Frontend tamamlandığında, backend ile entegre edilerek uygulama tam olarak kullanılabilir hâle gelecektir 🎉
